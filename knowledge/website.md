# Sreehari Suresh – Portfolio Website Design

## How was Sreehari's portfolio website designed and built (the site's design, UI/UX, layout and front end)?
UI/UX design isn't Sreehari's background, so he built his portfolio website with AI tools: the first version on Lovable, then he moved it to VS Code and continued with Claude Code. The design decisions were his, and the AI tools implemented them. This covers the website's design and front end only.

## What design decisions did Sreehari make for his portfolio website?
Sreehari made the design decisions for the website's redesign, and AI tools implemented them (Lovable for the first version, then Claude Code). His decisions included:
- Choosing his own colour palette: a dark #1F1F1F background, warm neutral text colours, and a single coral accent (#F76F53) used only for buttons, links and graphical elements.
- Removing decorative "AI template" effects such as a loading screen, particle backgrounds, glow effects and an animated neural-network graphic, so the content stands out.
- Replacing self-rated skill percentage bars with plain skill tags.
- Rebuilding the Projects section from his GitHub repositories, with descriptions that match the actual code, and separating featured projects from open-source ones.
- Layout and usability choices such as aligned sections, centred headings, a floating navigation bar that highlights the current section, and a prompt that invites visitors to try the AI assistant.
This covers the website's design and front end only.

## What is Sreehari's portfolio website built with (the website's tech stack)?
The website is built with TanStack Start, React 19 and TypeScript, using Vite, Tailwind CSS v4, shadcn/ui components (built on Radix UI) and the motion library for subtle animations. The typography is IBM Plex Sans and IBM Plex Mono. It is hosted on Vercel, and every update to the main branch on GitHub is deployed automatically.

## What is on Sreehari's portfolio website?
The website has these sections: a hero with his name, current roles, a short summary, his photo and key numbers (10+ AI/ML projects, 98% best detection accuracy, 71% inference latency reduction, 2,500+ images annotated); About, with his interests and quick facts; Experience, as a timeline of his roles; Projects, with featured projects and open-source projects linked to GitHub; Skills; Education and certifications; and Contact, with a contact form and direct links. Messages sent through the contact form reach Sreehari instantly on his phone through a Telegram bot. His resume can be downloaded as a PDF from the navigation bar and the hero section, and the AI assistant can be opened from the chat button at the bottom right.

## Is Sreehari's portfolio website mobile-friendly and accessible?
Yes. The layout is responsive and was checked on phone (375px), tablet (768px) and desktop (1366px) widths without sideways scrolling. On phones the navigation collapses into a menu and sections stack into one column. It respects the "reduce motion" setting in the visitor's operating system, supports keyboard navigation with visible focus, and the navigation marks the current section for screen readers.

## Is Sreehari's portfolio website open source, and what does it cost to run?
Yes. The full source code is public on GitHub: https://github.com/SreehariSureshGithub/sreehari-portfolio. The website runs entirely on free tiers, so it costs $0 a month to host and run.
